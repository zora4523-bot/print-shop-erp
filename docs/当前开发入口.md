## 最近十天形成的现行行为

### 生产准备、安排与完成

- 提交、核价、管理员保存和修改审批自动核对保存费用与生产资料，没有独立确认／下发步骤。核价成功可返回 `productionReadiness.ready=false`，表示终价已保存、资料仍待补齐；不等于已安排生产。
- 厂内任务由管理员直接安排师傅，每项任务一位负责人；同事务生成工序、归属与打印请求。每批最多 20 张工单、100 项任务，整批原子提交。
- 寄样直接发货；外协通过外协工单发出、回货。混合工单仍安排厂内师傅并校验外协回货，不能把所有非厂内场景都当作“免校验”。
- 师傅点“完成生产”按计划量登记，数量有出入走审批。管理员批量完成或首票确认发货可按规则代登记；待审批、未安排师傅、雇佣期和已结算工资边界保留。
- 旧扫码工单与单人流程互斥，旧工资、历史实际生产与补发义务保留。取消下发按钮不等于可删除内部 release、状态枚举、工序物化或已应用迁移。

代码入口：[自动准备](../lib/order/production-readiness.ts)、[用途路由](../lib/production/routing.ts)、[安排事务](../lib/production/dispatch.ts)、[计划完成](../lib/production/planned-completion.ts)。提交：`830c7ae7`、`97fd34a8`、`74594132`、`de9d169b`。旧 V2 [派单／抢单设计](ORDER-PRICING-AND-DISPATCH-V2.md) 的相关部分已被替代，不再作为实施任务。

### 经营分析

`/owner/analytics` 提供经营总览、订单与收费、成本与差额、工艺与纸张、采购与库存五个视图。
页面和 CSV 复用筛选与报表服务，导出完整汇总与全部明细，不限当前页。不同指标按其业务日期统计；当前库存不是日期区间累计值，未知成本不能当零成本或利润。

代码入口：[视图](../lib/analytics/views.ts)、[筛选](../lib/analytics/filters.ts)、[查询服务](../lib/analytics/service.ts)、[导出](../lib/analytics/export.ts)。提交：`2850f39e`、`5b28bd09`、`4923f5f5`。证据：[功能验收](audits/2026-10-03-analytics-release-acceptance.md)。

### 打印、PDF 与 CDR

- 「打印」打开 HTML 打印页，关闭打印对话框后记录内容摘要与尝试；浏览器不能证明纸张实际打印成功。单张 PDF 下载只取文件，不写打印回执。
- 批量 PDF 先取得文件再整批记录；记录成功或结果未知时交付，结果未知沿同一尝试重试记录。明确被拒绝时不交付旧文件。
- 单张 PDF 支持 direct/queued，最近已记录生产仍用 queued + durable。HEAVY 有真实中文 PDF／私有产物存储能力探针，心跳在线不等于 PDF 可用；浏览器池串行复用。
- 管理工作台可按外部销售账号批量打包 CDR；来源清单、过期、撤销、更新标记和下载权限继续校验。队列验收包含真实 ZIP 与失败恢复，不以按钮出现或 mock 成功代替。

代码入口：[打印记录](../lib/order/print-record.ts)、[批量打印](../lib/order/batch-print.ts)、[PDF 能力](../lib/pdf/capability.ts)、[CDR 工作台](../lib/cdr/workbench.ts)。提交：`67d28b19`、`be9d1c36`、`afd21616`、`1601b2a7`、`a494c4f5`、`231c7629`。契约：[跨设备打印](跨设备打印与可用性.md)；证据：[CDR 验收](audits/2026-10-02-cdr-workbench.md)。

### 账单、费用与寄样

已结算工单在关联月账单尚未确认时可按约束更正；账单确认后通过补收／抵扣等追加记录处理，不覆盖冻结历史。账单明细、金额、名称和导出保留快照，销售访问始终按本人归属限定。
寄付样品首重规则按已发布价目与省份计算，超重／运费调整走管理员履约费用；顺丰到付与缺失快照不能套成中通首重。

代码入口：[结算更正](../lib/order/settled-correction.ts)、[月账单命令](../lib/agent-monthly-billing/commands.ts)、[结算明细快照](../lib/agent-monthly-billing/settlement-detail.ts)、[费用核价](../lib/order/pricing-review.ts)。提交：`1cfd8c5e`、`68b63784`、`37b90c48`、`18b5d10b`、`fec7ef66`。具体输入、状态和错误契约看 [API](../API.md)。

### 身份、表单与 UI

- 角色只有 ADMIN／SALES／WORKER；工种只有 MACHINE／PACKER。管理员收费建单选择外部销售；客服、内部／工厂直单、清废／厨师及其已删除定时任务不能根据旧设计重新实现。
- 工单不再录入／展示客户名称简称，以归属外部销售辨识；旧数据库列和历史请求兼容按实际消费方保留。设计款名称由建单人填写，同一设计组规格共用、同单不重名。
- 表单保留失败输入、提交反馈、离开保护与草稿恢复；采购／BOM 独立恢复和创建幂等不得被普通页面重构替换。
- 二级页返回统一交给面包屑父级；侧栏分组、折叠和内容滚动按现行组件实现。当前共享响应式配置为九视口（含 320／390／430px），不把历史六视口记录扩大为九视口通过。

代码入口：[schema](../prisma/schema.prisma)、[外部销售名称](../lib/order/external-sales-name.ts)、[表单草稿](../lib/form-drafts)、[共享视口](../scripts/lib/playwright-config.ts)。提交：`96e88330`、`e6520e2e`、`47e7951d`、`2352dd34`、`a009f485`、`b72a5e1f`；其余修复见同期间 Git 记录。
