## 保留的业务与安全边界

- 工单入口继续执行角色、所有权及状态校验。数据库读取仍在原事务、原加锁位置之后执行，没有新增事务或把写入移到锁外。
- 终价校验仍核对业务版本、价格版本、款式归属、包装组模式/袋数、逐票省份/重量与收费业务标识；金额仍用 Decimal，不接受覆盖已锁定快照价。
- 盘点继续按原锁序执行账面回声校验、部分过账、事务内 outbox 写入和提交后通知降级；没有改动并发或幂等语义。
- 通知保留角色关闭不回退、管理路由完整性、客服隐私收件上限、租约检查、发送前预留及未知结果禁止自动重发规则。
- UI 表单状态、提交锁和动作执行留在原组件；提取的展示组件不增加 DOM 包装层。服务端金额展示权限条件保持不变。

## 测试修复

- 月账单导出测试的固定过期时间原先会与真实系统日期脱节。只对测试中的 `Date` 使用固定时钟，保留真实异步计时器；生产导出逻辑未改动。
- 增加“开始执行时恰好过期”和“生成文件期间过期”两项用例，确保未生成/未发布过期文件，未放宽过期检查。
- 通知 E2E 的“企业微信群 / 新建群”选择器已落后于当前“企业微信通知目标”界面。更新实际控件名称，显式选择 Webhook 兼容路径，并断言默认未绑定智能机器人不能启用。保留路由配置、模拟发送和历史日志阻止删除的完整验证。
