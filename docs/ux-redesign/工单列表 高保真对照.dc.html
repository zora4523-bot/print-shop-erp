两版结构完全一致——同样的保存视图、常驻筛选行、已选条件 chips、六列可见的表格、行内动作、分页。唯一变量是视觉语言：1a 用 Industry（钢蓝 + Barlow Condensed + 直角 + 发丝边 + 十字定位标），1b 用你们现有的 shadcn 皮肤（白卡 + 圆角 + 柔阴影 + 红主色 + 系统 CJK 字体栈）。看完选一个，我就照它把设计语言钉死。

别把两个变量混起来看
两版相对当前实现都改了同样四处结构，且只有这四处：① 表格六列全部可见（当前 1280 下只渲染 3 列、状态/交期/金额/动作被容器裁掉，这是本批最高优先的 Blocker）；② 折叠筛选面板改成常驻一行 + 已选条件 chips 永远可见（当前折叠后只剩一个「已启用」布尔徽章）；③ 新增保存视图，取代每天在 30+ 字段里重选同一组条件；④ 补行内动作，取代「进详情再返回」且返回后筛选丢失。这四处与皮肤无关——你选 1b 也照样要做。
外壳是忠实还原的，没动：侧栏仍是截图里的三组（概览 / 业务 / 财务，13 项，含「开机师傅计件规则」「员工工资规则」），没有补「主数据」「运维」两组；顶栏仍保留 工单 / 排产 / 采购单 / 仓库/库位 四个与侧栏重复的链接，也仍然没有全局搜索、没有常驻告警入口。这些都是线框文档里的建议，属于另一个议题，故意不放进这一屏——否则你分不清自己在选视觉还是在选结构。
