本批最重的一条
观察（salary-daily-light 1280）：「重算该日全员日薪」是整页唯一的红色主按钮，和日期选择器并排放在最显眼的位置——而它会覆盖该日已生成的全员工资数据，是标准的 L3 不可逆操作。同一页上「导出 Excel」这种零副作用的动作反而是次要样式。另外日期出现在两处（重算卡一个、筛选卡一个），两个 date input 各管各的，用户很容易在 A 日期下按了 B 日期的重算。
