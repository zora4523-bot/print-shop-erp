批次三 · 工单：列表 → 新建 → 详情 → 修改审核

你点名的痛点：「工单页太繁琐，在保证功能正常的情况下尽可能高效率」。所以这一批不做减字段——旅程文档明确「不得删掉对计价和生产有意义的字段」——而是改录入节奏：把一次性长表单拆成「三段 + 常驻摘要」，把款式从「全部展开堆叠」改成「摘要行列表 + 一次只开一款的编辑区」，把重复劳动交给「按上次 / 复制上一款」，把校验从提交后报错改成常驻清单可点跳。
