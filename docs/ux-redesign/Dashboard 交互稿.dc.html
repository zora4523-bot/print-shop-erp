批次三到八都出了交互稿，只有批次二停在线框 —— 而它是每天的入口。证据：dashboard-light 1280 与 393 都打开过。首屏顺序是 160px 问候卡 → 4 张 KPI → 4 张快捷入口 → 才轮到超期外协与待发货工单，而那两张卡里的表格右侧被容器裁掉，「进…」动作链接切没了。侧栏为现状 13 项。

这一屏里有三处是提案，不是现有能力
① 本月经营摘要里的毛利率依赖经营分析立项——毛利是推导指标，系统里没这个字段，口径未定之前不要在 Dashboard 上渲染具体数字。② 上次查看需要按人记录的 last-viewed 存储，现在没有。③ 查看已处理需要一个 dismissal 存储：超期外协这类信号是从外协单算出来的，本身没有独立的「已处理」状态。三条都已在界面上标「提案」，实现前需先拍板。
