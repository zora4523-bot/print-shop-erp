# 管理员收费编辑

起点：`2bc12e6b`，工作区干净。范围为管理员收费权限与入口、现有核价接口扩展，以及必要回归测试；无数据库结构变更。

## 实现边界

- 保留既有新建、草稿、提交复核、文件上传、制版、物流、改单功能。
- 管理员可修改自动或人工加工单价、一次性费用、包装加工单价、订单级收费、逐地址物流费用；工厂直接业务支持首次补录物流收费。
- 逐款制版沿用数量、单价及版费关联校验；新增收费和优惠沿用有说明、原因及审批信息的商业明细接口。
- 新建入口先完成提交再编辑费用，避免提交报价覆盖人工输入。草稿仍可使用既有加工／包装人工价字段。
- 外部销售不开放改价。寄样只收快递和耗材，打样只收整单价。到付运费不得改为非零。
- 已结算、归档、作废、免费单禁止全项改价；版本冲突及待审批申请拒绝写入。金额使用 Decimal，更新、价格修订、审计及内部销售差额记账复用现有事务。
- 未修改的自动报价记录不转为人工价格。参考价来自订单保存的报价依据；修改当前价格配置不会重写此记录。
