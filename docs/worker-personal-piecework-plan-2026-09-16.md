# 师傅个人工价与计薪次数

状态：计薪次数与账号个人工价已实现；以下保留原规划与分批验证记录。个人工价任务起点 `ce71ac57`，工作区干净。正式工价需管理员按实际约定发布。

## 业务边界

- 工单局部烫金的计薪过版次数由管理员设置，默认正反面颜色总数。生产数量、颜色和工单进度不变。
- 同一工序可能合并多个过版数相同的款式，编辑入口必须列出全部款式，调整适用于整个工序。需要款式分别计薪时，先拆分工序，禁止在同一工序隐藏不同倍数。
- 师傅个人工价由管理员在师傅账号设置，师傅只能查看本人适用工价，不能给自己调价。
- 工资仍归实际报工的 `reporterId`，不会按工单创建者、认领人或管理员分配人汇总。
- 客户报价独立。个人工价使用每下/每个/每袋/每盒的金额，不是客户售价的百分比提成。

## 本次计薪次数调整

`ProductionOperation.payrollPassCount` 为空时按原颜色次数；`payrollRevision` 用于并发检测。
管理员在工单详情编辑 1–999 的整数和原因，核对后保存。订单→工序锁与报工、改版保持一致。
仅当前版本、可生产状态、未完工的局部工序可调整。已完成/取消工单不开放。
报工页带计薪版本，管理员调整后旧页面提交必须刷新。成功请求重试仍返回原报工，不重复计薪。
报工保留当时实际计薪次数、版本、工价和金额。历史记录不重算。
工单改版生成新工序后重新按新颜色数带出，管理员需重新核对；不把旧工序的人工调整盲目带到新款式。

## 账号个人工价：实现规格

### 1. 管理入口与适用范围

在“用户管理 → 编辑师傅 → 计件工价”维护，与员工薪酬规则建立互相可达的入口。
只显示该账号岗位可报的工序：局部烫金每下、专版每个、包装每袋/每盒。
每个账号明确选择“使用统一工价”或“使用个人工价”，显示当前、待生效及历史版本。
不擅自给现有师傅填价格；没有个人模式版本的账号保持统一工价，页面明确显示该模式。
个人模式缺少已发布的适用工价时拒绝报工，不悄悄回退统一价。0 元与未配置严格区分。

### 2. 版本数据模型

复用 `PieceworkPriceBook` / `PieceworkPriceRule` 的草稿、发布、金额精度和审计，增加工价作用域及可选师傅外键。
增加账号工价模式的生效版本记录，避免切换模式时丢失取价依据。统一与个人工价按各自作用域保持生效区间不重叠。
现有工价簿全局版本和发布约束、唯一索引、数据库报工价格校验触发器、发布脚本必须一起调整，不能只在页面加金额字段。
发布后的价格与适用账号不允许修改/删除；停用账号只停止新报工，不删除历史价格。

### 3. 取价与历史保护

在报工事务中根据会话账号、数据库报工时点、岗位、单位和模式版本选择唯一有效工价。
将模式版本、价格来源、适用账号和工价版本写入报工快照；现有 `priceBookId/rate/amount` 继续作为结算依据。
账号资格锁、工价发布锁、结算日锁须统一排序；取价与写报工不可被账号切换/发布插入。
师傅看到本人金额与公式；不要把其他师傅价格传入客户端。
已有报工按原金额；更正采用现有追加冲正流程，不能批量改历史金额。

### 4. 统计与结算

复用按 `reporterId + 上海业务日期` 的计件汇总和结算，不新增另一套工资账本。
同一工单两位师傅不同单价，分别按各自报工记账；汇总应等于有效报工金额之和。
导出增加价格来源与个人工价版本，保留旧记录解释能力。不能用账号当前价反推历史工资。

### 5. 验证与上线次序

1. 领域取价和前向迁移，fresh DB 全迁移链、旧记录前后对比。
2. 管理端账号工价编辑/发布，师傅本人适用价展示；越权与他人工价隔离。
3. 两位师傅相同数量不同工价；同一天调价前后、未来生效、模式切换、零价/缺价、岗位改变/账号停用。
4. 报工与发布/调整/结算并发；重试不重复计薪；旧页面拒绝；历史工资不变。
5. 全量单测和覆盖率、真实框架 E2E、六视口明暗主题/触控/键盘/axe，正式价格确认后部署。

实现与验证进度见文末；不用测试金额代替正式工价。

## 个人工价实现（2026-09-17）

入口：管理员 → 用户管理 → 编辑师傅 → 计件工价。员工薪酬规则页提供账号入口。
按账号当前岗位显示局部每下、专版每个或包装每袋/每盒；停用、非计件岗位不能编辑。
管理员可保存草稿、核对差额并发布，支持立即或未来生效；模式切回统一工价也要发布。

复用工价簿保存模式版本：`workerId` 为空为统一工价，非空为账号作用域；`useUnifiedRates` 表示该账号从生效时点使用统一价。
因此无需另建模式表。无个人记录表示原有统一模式，不为旧账号伪造已发布版本。
全局版本号仍唯一；不同账号交错发布时，单个账号的版本号可以不连续。
每个作用域独立限制一个草稿、同一时刻一个已发布版本；已发布价格、账号和模式不可修改。

报工事务按实际报工账号与数据库时间取价，缺个人价时拒绝报工，不回退统一价。
师傅只收到本人适用价格；旧页面带工价版本键，调价后必须刷新核对。
报工快照保留价格来源、模式版本、适用账号；结算与按账号统计继续使用原报工金额。
导出增加工价来源和账号工价版本，旧报工按原统一工价解释。

新增两条前向迁移：个人作用域与数据库报工校验、每作用域独立草稿索引。未改旧迁移。
浏览器测试暴露原全局单草稿索引遗漏，已以前向迁移补齐；测试个人报工使用独立工序，避免污染原主流程 fixture。
