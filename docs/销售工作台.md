# 销售工作台

入口：`/workbench`。销售与客服菜单显示「工作台」，管理员菜单显示「销售工作台」，保留原有 `/owner` 经营工作台。页面与计算 action 均使用 `order:create` 权限，师傅不可访问。

## 功能和来源

- 设计参考：[用户提供的销售工作台原型](https://claude.ai/code/artifact/b64f9446-cf8e-4972-a4d8-062239f7e7ec)。沿用报价计算、纸张与规格、话术应对三个分区，视觉使用项目 UI 规范。
- 用户确认价格使用系统当前规则。产品、规格、纸张和烫金颜色读取建单目录；加工费通过 `calculateCreateOrderQuoteFromCatalogInTx` 读取当前发布价格并复用正式计价引擎。加价使用 Decimal、人民币分精度、四舍五入。
- 计算器为单款快速计算，支持当前系统的局部烫金、专版烫金与彩印路线。彩印快捷口径为 CMYK 四色、无覆膜，加烫金按专版；复杂组合、包装及物流在正式建单流程确认。现有通版路线要求局部烫金，因此不把原型「不印刷空封」强行映射为通版报价。
- 只显示加工费及其加价，不将其称为含制版、包装、物流的完整对客总价。缺价保持待核价，不把已知部分当成总金额；不采用原型固定价格、虚构历史成交参考或内部机台成本。
- 编辑任一计算条件即清除旧结果，旧请求晚到不会覆盖新条件；条件完整且有效时自动重新取得当前价格，也保留手动计算入口。
- 纸张与规格显示当前目录，纸张推荐与 17 个话术场景是静态销售资料，支持全文搜索、分类筛选、折叠与复制。调整了原型中未经核实的包邮、固定交期、固定色差百分比、质量保证及退款承诺。
- 产品目录加载失败时，显示重试入口，仍可查看销售资料。资料不保存客户信息，不新增数据库表或变更订单金额。

- 首次复查将无可选内容的下拉框禁用；其中选择产品前的规格、纸张限制已由下方「规格与纸张直接选择」流程替代。
- 增加全部颜色选择/取消、所有数量和加价快捷值、非法数字阻止提交、跨分区保留输入、路线切换清理关联值、彩印取消烫金、失败后重试的浏览器检查。
- 逐分类展开、收起并复制全部 17 条话术，核对复制文本与对应话术一致；保留搜索无结果、清除筛选与复制失败检查。
- 真实目录 E2E 遍历三条路线的全部产品、规格、纸张及工艺；每个产品按第一项规格/纸张实际计算各工艺，并输出 `catalog-selection-audit` JSON 附件。此检查覆盖选项遍历，不代表全部参数的笛卡尔积均有价格。
- 当前「紫色珠光纸」目录缺少纸张克重，计算会明确提示补充产品资料；未替管理员填写克重或修改价格。E2E 明确检查此已知资料异常，其余产品仍要求取得当前价格版本。

复查验证：工作台浏览器 20 项通过；全量 Vitest 5,909 项通过、55 项条件跳过；工作台 E2E 4 项通过；类型检查、lint、架构门禁通过。

真实目录遍历结果：35 个产品、35 个产品规格选项、125 个产品纸张选项（跨产品重复计数）全部可选择；提交 51 次工艺计算，其中 33 次取得完整加工费、15 次按系统规则显示待核价、3 次明确提示缺少克重。待核价为 5 个标准专版产品选用首项「120g珠光艳闪」时的平烫/浮雕/激凸组合；另外验证的大号封 160g 珠光艳闪完整报价用例仍通过。缺克重的 3 次对应「紫色珠光纸」的 3 种工艺。未修改目录或发布价格。

## 规格与纸张直接选择（2026-09-10）

根据页面标注反馈，取消「必须先选产品」的限制。初始规格、纸张从当前产品类型的真实目录汇总，打开页面即可选择；按已选条件缩小匹配范围，唯一匹配时自动选中产品。存在多个匹配产品时提示继续选择或手动确认，不擅自替用户选第一项。也保留先选产品的操作方式。

新增「重新选择产品、规格和纸张」入口，清空三项关联条件并使旧报价失效；切换类型仍清空关联选项。只有目录本身确实为空时才显示「暂无可选项」。所有报价仍由服务端校验产品、规格和纸张归属并按系统当前价格计算。

新增浏览器与真实目录 E2E 验证先选规格、先选纸张、自动匹配、清空后重新选择及实际报价；原有全目录遍历、颜色上限、数量/加价、三分区、17 条话术与异常恢复检查继续执行。

本轮验证：22 项工作台浏览器测试、5 项真实目录 E2E、5,909 项单测通过（55 项条件跳过），类型、lint 与架构门禁通过。在用户标注的浏览器中直接选择大号封和 160g 珠光艳闪、1,000 个、单面亚金平烫，加价 35%，得到加工费 325 元及参考报价 438.75 元；未预先选择产品。既有缺克重和待核价目录项的处理保持不变。


## 自动报价（2026-09-10）

之前报价只由表单提交触发。本轮补充自动计算：选齐产品、规格、纸张、烫金颜色（无烫金彩印除外），且数量与加价比例有效后，停止修改 500 毫秒自动调用原有报价 action。修改任意报价条件重新触发；输入不完整、空值或超出范围时不请求。连续输入合并为最后一次计算，切换条件、清空和卸载都会使旧请求失效。

自动更新不移动输入焦点。保留「计算报价」用于立即计算和失败后重试；手动计算取消尚未执行的自动任务，防止重复请求。缺价与资料缺项仍按原有提示处理，不添加固定价格或修改计价规则。

运行页面实测未点击计算按钮：大号封、160g 珠光艳闪、正面亚金平烫、加价 35%，1,000 个自动报价 438.75 元；改为 2,000 个自动更新至 769.50 元，焦点仍在数量输入框。当时价格版本为 8，金额仅作验证记录。

本轮验证：25 项工作台浏览器测试、6 项真实目录 E2E、5,909 项单测通过（55 项条件跳过）；类型、lint、UI 与架构门禁通过。新增用例不点击计算按钮完成首次报价，再自动计算数量及零加价变化，并覆盖连续输入、同值快捷按钮、手动请求去重和旧自动响应晚到。
