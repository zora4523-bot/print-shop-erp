# 销售工作台

此前功能复核、缺陷修复及生产构建验证范围见 [2026-09-10 工作台审查](audits/2026-09-10-workbench-readiness.md)。下文历史测试数字只代表对应记录时点。

入口：`/workbench`。销售菜单显示「工作台」，管理员菜单显示「销售工作台」，保留原有 `/owner`「管理工作台」。页面与计算 action 均使用 `order:create` 权限，师傅不可访问。2026-09-24 起 `order:create` 只给 ADMIN 与 SALES（客服角色已删除）；管理员在工作台选择寄样品 / 打样时，样品表单显示必填的「关联外部销售」下拉，工作台页面为管理员加载外部销售列表，没有启用的外部销售时显示空状态。

## 当前功能（2026-09-13）

- 报价计算和创建工单使用同一款式字段组件、目录选择/联动函数及建单报价 schema。默认沿用建单的局部烫金条件；纸张、克重、规格和颜色来自管理员配置的有效目录。多产品匹配时由用户选择，不擅自取首项。
- 支持局部烫金、专版烫金、彩印；覆膜、正反面烫金、局部/专版加烫和改尺寸沿用建单字段含义。缺价仍为待核价，停用/缺失工艺明确提示，不补造价格或工艺。
- 当前 UI 调用 `quoteWorkbenchItemAction({ item })`，服务端通过 `calculateCreateOrderQuoteFromCatalogInTx` 读取当前发布价格。数量和工艺等条件改变后立即清除旧价，停止输入 500 毫秒后报价；晚到响应不能覆盖新条件。自动报价保留输入焦点，刷新/重试报价完成后定位结果标题。
- 加价比例只在本地对基础加工费使用 Decimal 运算，按人民币分四舍五入；支持 0–100 的整数，默认 35%。改变加价不重新请求服务端。参考价只包含加工费及加价，包装、运费另计；需制版的情况保留待定提示。
- 页面使用“款式条件”和“加工费参考报价”两栏，窄屏按阅读顺序纵向排列。费用明细按需展开，不重复展示产品/规格/纸张的旧筛选表单或长期解释卡片。
- “按此款式创建工单”把当前款式带到建单页；只传事实，不传参考价、加价或签名。条件按当前账号保存在 sessionStorage，30 分钟有效。目录变更导致事实不再匹配时，要求重新选择。建单页重新核价，正常创建/提交仍使用原权限与金额校验。
- 已有未完成工单时，可继续原工单，也可把本次报价另存为独立草稿。报价带入后的刷新恢复其自己的草稿，不覆盖原草稿。侧栏顶部普通“新建工单”打开常规新建页；工作台功能栏不再重复这个通用入口（2026-10-02）。
- 常规新建页提供“报价工单草稿”恢复入口，只列出当前账号、当前计价身份下可恢复的草稿；未完成工单名称及保存时间用于辨认。临时报价条件过期或新标签页中不存在时，已经保存的工单草稿仍可继续。
- 草稿完整保留覆膜条件。旧彩印铜版纸草稿若缺少覆膜资料，保留其他填写内容并提示重选，暂停自动报价；不能把未知覆膜默认为亚膜。损坏草稿会尝试有效的临时报价条件，两者均不可用时要求返回工作台重新选择。
- 烫金色使用管理员配置名称作为选择值，不再把“哑金”等名称强制改成别名。铜版纸的中文名称及 `COATED`、`TBZ` 标签使用同一个业务判断，控件展示与保存的覆膜条件保持一致。
- “纸张与规格”和 17 个话术场景继续支持搜索、分类、展开和复制。目录加载失败不阻断销售资料阅读。

## 自动报价（2026-09-10）

之前报价只由表单提交触发。本轮补充自动计算：选齐产品、规格、纸张、烫金颜色（无烫金彩印除外），且数量与加价比例有效后，停止修改 500 毫秒自动调用原有报价 action。修改任意报价条件重新触发；输入不完整、空值或超出范围时不请求。连续输入合并为最后一次计算，切换条件、清空和卸载都会使旧请求失效。

自动更新不移动输入焦点。保留「计算报价」用于立即计算和失败后重试；手动计算取消尚未执行的自动任务，防止重复请求。缺价与资料缺项仍按原有提示处理，不添加固定价格或修改计价规则。

运行页面实测未点击计算按钮：大号封、160g 珠光艳闪、正面亚金平烫、加价 35%，1,000 个自动报价 438.75 元；改为 2,000 个自动更新至 769.50 元，焦点仍在数量输入框。当时价格版本为 8，金额仅作验证记录。

本轮验证：25 项工作台浏览器测试、6 项真实目录 E2E、5,909 项单测通过（55 项条件跳过）；类型、lint、UI 与架构门禁通过。新增用例不点击计算按钮完成首次报价，再自动计算数量及零加价变化，并覆盖连续输入、同值快捷按钮、手动请求去重和旧自动响应晚到。

## 对照 HTML 原型修复默认核价（2026-09-10）

实际打开原型 iframe，读取其计算脚本并修改数量验证。原型 `ST` 默认选择专版、大号、第一种基准纸、1,000 个和 35% 加价；单面单色是隐含条件。规格、纸张、数量、工艺和加价的 `onchange/oninput` 调用 `draw()`。原型从固定数组取数量阶梯价，加纸张和工艺单价后乘数量，再加烫金及特殊效果费用，最后乘 `1 + markup`。因此原型进入即出价，而工作台此前缺少产品和正面颜色默认值，还可能选到缺克重或缺价格的首项纸张，导致不出价或只有笼统的待核价提示。

工作台现在从实时目录选择常用默认条件，优先大号封、160g 珠光艳闪/红卡；彩印优先 200g 铜版纸。数量默认 1,000 个、加价 35%、平烫默认一个正面颜色，彩印默认无烫金。默认候选仍需有可解析规格和明确克重；目录缺项时不伪造选项。进入页面及切换产品类型后可直接自动计算；切换规格保留兼容纸张并重新匹配产品，已明确选择的产品在更换其自身规格或纸张时保持选中。重置入口仍支持从规格或纸张重新选择，多匹配时由销售确认产品。

未选颜色或输入数字不合法时，报价区说明需要补充的具体字段。系统缺价显示具体原因和恢复方式；只选反面、专版双面和彩印反面组合仍提交正式计价引擎，由当前版本决定能否计算，当前不支持时返回明确提示。2026-09-24 起彩印叠加烫金（局部或专版）带反面颜色显示人工核价提示；非彩印专版带反面仍被拒绝（待业主确认）。未修改正式引擎、目录、价格或订单。初始候选符合常用资料条件不等于保证已发布价格，实际缺价仍由引擎返回待核价。

原型的固定烫金附加价和数量价格表不复制到系统。同为大号封、160g 珠光艳闪、单面单色平烫、加价 35%，原型固定表在 1,000 个时得到加工费 365 元（含额外 40 元烫金），参考价四舍五入显示 493 元；系统当时版本 8 得到加工费 325 元、参考价 438.75 元。按用户已确认的系统价格口径，以后者为准；2,000 个对应加工费 570 元、参考价 769.50 元。

本轮验证：全量 Vitest 5,926 项通过、55 项条件跳过；工作台浏览器 28 项和真实 E2E 8 项通过；类型、lint、UI、架构门禁与差异检查通过。E2E 验证首开零操作即 438.75 元，改数量为 2,000 个即 769.50 元，再直接改中号即 729.00 元，以及反面/缺价提示和修正后自动恢复。真实目录遍历覆盖三路线的 14 个规格选项、35 个产品、125 个产品纸张选项及 51 次工艺报价：33 次完整、15 次明确待核价、3 次缺克重，后两类仍对应上述 120g 珠光艳闪和紫色珠光纸资料问题。

开发预览已打开的旧表单可能被热更新保留输入；完整刷新后才应用新的初始默认条件。本轮恢复了本地 3000 端口服务，并在重新打开的预览中确认默认报价与缺价提示。


## 纸张边界修复（2026-09-11）

根据对 `dbbe06a` 的 Grok 对抗审查和独立复现，补齐缺货/失效提示与纸张控件的可访问描述关联。关联纸张仍在目录但缺克重时，字段和报价区明确说明需要补充资料或改选产品，不再要求操作已禁用的纸张下拉框；改选可用产品后恢复自动报价。

纸张选项保留完整显示名称。报价 action 先按当前目录核对选项，再使用现有规范化函数分离纸张名称与克重，交给订单原有 32 字名称校验及正式计价引擎。合法 32 字名称增加克重前缀后不再误判超长，不截断名称、不放宽订单字段或修改价格。规范化后名称仍超过订单限制的材料给出明确人工核价提示；不假装所有 64 字物料名都可自动报价。

验证、边界和未覆盖项见 [纸张修复验收](audits/2026-09-11-workbench-paper-fixes.md)。此前审查与测试记录保留原时点结果。
