# 销售工作台

入口：`/workbench`。销售与客服菜单显示「工作台」，管理员菜单显示「销售工作台」，保留原有 `/owner` 经营工作台。页面与计算 action 均使用 `order:create` 权限，师傅不可访问。

## 功能和来源

- 设计参考：[用户提供的销售工作台原型](https://claude.ai/code/artifact/b64f9446-cf8e-4972-a4d8-062239f7e7ec)。沿用报价计算、纸张与规格、话术应对三个分区，视觉使用项目 UI 规范。
- 用户确认价格使用系统当前规则。产品、规格、纸张和烫金颜色读取建单目录；加工费通过 `calculateCreateOrderQuoteFromCatalogInTx` 读取当前发布价格并复用正式计价引擎。加价使用 Decimal、人民币分精度、四舍五入。
- 计算器为单款快速计算，支持当前系统的局部烫金、专版烫金与彩印路线。彩印快捷口径为 CMYK 四色、无覆膜，加烫金按专版；复杂组合、包装及物流在正式建单流程确认。现有通版路线要求局部烫金，因此不把原型「不印刷空封」强行映射为通版报价。
- 只显示加工费及其加价，不将其称为含制版、包装、物流的完整对客总价。缺价保持待核价，不把已知部分当成总金额；不采用原型固定价格、虚构历史成交参考或内部机台成本。
- 编辑任一计算条件即清除旧结果，旧请求晚到不会覆盖新条件；点击计算重新取得当前价格。
- 纸张与规格显示当前目录，纸张推荐与 17 个话术场景是静态销售资料，支持全文搜索、分类筛选、折叠与复制。调整了原型中未经核实的包邮、固定交期、固定色差百分比、质量保证及退款承诺。
- 产品目录加载失败时，显示重试入口，仍可查看销售资料。资料不保存客户信息，不新增数据库表或变更订单金额。

## 验证入口

- `actions/__tests__/workbench.test.ts`：鉴权、输入与目录校验、真实计价引擎、最小返回投影、双面烫金及失败关闭。
- `lib/workbench/__tests__/quote.test.ts`：Decimal 加价边界与未知金额。
- `app/(admin)/__tests__/workbench-page.test.tsx`：页面授权与目录失败降级。
- `components/business/workbench/__tests__/SalesWorkbench.browser.spec.tsx`：六视口、明暗主题、触控、axe、搜索、复制与旧请求失效。
- `tests/e2e/workbench.spec.ts`：真实登录与工作台菜单、当前目录计算、跨角色拒绝。

- `pnpm test --run --maxWorkers=2`：568 个测试文件通过、3 个按条件跳过；5,908 项通过、55 项跳过。默认并发与其他检查同跑时曾有 4 项原有 PostgreSQL 测试达到 5 秒超时，降低并发后全量通过，未调整断言或超时。
- 工作台浏览器测试 15 项、共享导航浏览器测试 29 项通过；覆盖六视口、明暗主题、触控与 axe。
- 工作台 E2E 3 项通过，含真实目录的通版与专版计算、客服访问、师傅拒绝。首次冷编译登录超时，预热后重跑通过。
- `pnpm typecheck`、`pnpm lint`、`pnpm check:architecture`、`git diff --check` 通过；最后的报价展示组件拆分后补验类型、浏览器与 UI 文案/令牌检查。
- 本地实际核对桌面报价与话术页；大号专版、160g 珠光艳闪、1,000 个、单面单色平烫在当时价格版本 8 下加工费为 325 元，加价 35% 后为 438.75 元。此例仅记录验证结果，不作为页面固定价格。
