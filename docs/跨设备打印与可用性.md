# 跨设备打印与可用性

2026-09-11 实施；代码验收结果另记于本文件末尾。此方案不等于已部署或已完成真机/打印机验收。

## 不变量与支持边界

- 正式打印入口打开服务端 PDF，下载入口保存同类 PDF；网页预览保留。PDF 的生成本身不写打印回执；管理员从打印页完成打印、或下载批量打印文件时才记当前版本已打印（业主 2026-10-02 拍板「点打印即记已打印」，取代原“确认已打印”按钮）。
- 保留登录、账号有效性、角色/资源所有权、工单版本、后台任务所属用户、租约和追加式历史约束。下载前重新检查访问权与版本，不能通过对象名/旧 jobId 绕过。
- 主字体使用项目内 Noto Sans SC，编号使用 Noto Sans Mono；许可、来源、原始与发布摘要见 [字体清单](../public/fonts/print/README.md)。两份 WOFF2 共约 8 MiB，完整保留所选上游字符集。仅打印预览加载，普通业务页不增加此负担。
- PDF HTML 直接嵌入同一字体文件，不依赖操作系统字体、外部字体 CDN 或会话 Cookie。字体缺失/加载超时停止输出；图片的既有失败占位提示保留，不隐瞒图稿加载失败。
- 主体覆盖所选字体的中文、拉丁字符集；不承诺任意 Unicode/emoji、生僻字或图稿内部自带文字的字体一致。新增字形应纳入真实订单样本验收。
- 浏览器/系统抗锯齿可能不同；跨设备验证内容、分页、可操作性，像素基线只验证固定的运行环境。PDF 固定页面内容，但驱动、纸张和用户缩放设置仍影响实体输出。

## 实现与恢复

- `lib/order/print-fonts.ts`：网页/PDF 共用字体声明及 8 秒加载上限；先完成字体加载，再进行 A4 几何分页。
- `lib/pdf/render.ts`：检查字体与分页状态；`PDF_CHROMIUM_VERSION` 配置后拒绝版本漂移，异常释放页面。部署检查要求生产明确填写已验证版本。
- `lib/pdf/order-snapshot.ts`：打印内容与厂名摘要；只剔除 OSS 读取签名的临时时间/凭证，保留对象路径、图像处理参数和业务内容。worker 在生成前后核对摘要与访问权。
- 同一用户/角色、版本、内容摘要、公开源地址在一个数据库时钟的 15 分钟窗口内使用同一任务键。窗口切换允许新生成，不声称跨窗口永久去重。显式失败恢复创建新生成标识；已有 `jobId` 轮询不反复入队。
- PDF 产物保留 1 小时，可重复/并发读取，不再读后删除。身份与版本校验每次执行。过期/文件丢失提供重新生成；若任务仍运行则保留原 jobId 自动轮询。
- `filesystem` 用显式持久目录，0600 文件、0700 目录、随机临时名和原子 rename。Web/HEAVY 必须挂载同一持久卷；跨主机不能各用自己的同名本地目录。
- `oss` 用现有 OSS 客户端，固定 `private/order-pdf/` 前缀，上传显式 private ACL。Web 通过鉴权接口代理读取，不返回公开地址；读时检查 1 小时有效期。运维需为此前缀配置 1 天物理生命周期，并授予受限 Get/Put 权限。
- 重任务沿用数据库租约、心跳、崩溃恢复、两次自动尝试和 HEAVY 并发 1。队列失败/超时有恢复入口；不在 Web 中临时启动重型 worker。

## 配置、发布与回退

配置步骤唯一维护于 [部署指南](./部署指南.md#跨设备-pdf-发布检查)。本次不运行生产迁移、不写真实 OSS、不修改线上进程。

上线前必须核对：

1. 字体文件及许可随发布包提供，manifest 校验通过；固定 Node、依赖锁文件和已验收 Chromium 完整版本。
2. Web 与 HEAVY 使用同一存储配置；共享卷/OSS 的权限、过期行为、容量和失败告警实际验证。
3. 私有测试对象由 worker 写入、由另一 Web 实例读取同一字节，再确认未登录/他人/失效版本无法读取；内存 mock 不算真实 OSS 验收。
4. 测试 worker 中断与租约恢复；HEAVY 离线时排队提示正常，恢复后完成，不重复写打印回执。
5. 真机矩阵：Windows Chrome/Edge、macOS Safari/Chrome、iPhone Safari、Android Chrome。覆盖登录、开单、核价、下载/系统分享、长中文、长编号、慢网和键盘/触控。Playwright 的 WebKit/移动模拟不等于真实 Safari/iOS/Android 验收。
6. 实际打印机按 A4、100%/实际大小、关闭浏览器页眉页脚验证分页、二维码可扫及金额/内容正确性；本项目生产工单不显示价格。
7. 固定环境的新字体截图逐项确认后才更新基线；未经确认不覆盖旧图，也不降低阈值。保留旧版比较结果。
8. 发布失败回退代码、字体和 Chromium 为同一套已验收版本；存储配置兼容且保留未过期产物；无需数据库变更。

本次只改进打印链路的可恢复性。全站高可用仍取决于数据库、会话、负载均衡、存储、网络、监控与备份；不因本地测试通过声称完成基础设施高可用。

## 缺失资料与分页

缺失资料提示不再创建独立打印附页。首页保留简短提示，多款式的同类缺项合并展示；款式、图稿、长备注、地址和工序的实际内容仍按容量分页。PDF 内容标识包含模板版本，模板变化后新请求不复用旧版文件；更新模板后需重启 HEAVY worker。


## 批量打印

管理员工单列表选择当前页工单后点击“打印所选”，每批最多 50 单，按列表顺序
生成一份 PDF。每张工单从新页开始，保留自身页码、二维码和实际内容分页，不添加封面或分隔空白页。
生成成功同时提供下载和打开入口；浏览器不支持内联 PDF 时使用下载。
进度区区分排队、逐单生成和合并；两分钟后改为每十秒查询，直到完成，亦可手动查看。
相同账号、工单顺序及内容的进行中批次复用任务；同一十五分钟时间窗内有效的完成文件直接复用。
单张 PDF 按账号和内容标识缓存一小时，重叠批次只生成缺失文件；内容或模板变化自动失效。
点击“打印所选”准备文件，完成后打开 PDF 使用阅读器的打印功能，或下载后打印。
生成失败或工单内容变化时不提供部分文件，问题项按提交时的工单顺序标识，重新选择后重试。
当前选择范围限本页，不隐式包含其他分页或筛选结果。

长工单编号在限定宽度内换行，不能挤压页眉生成无意义续页。相对图稿地址按公开站点地址解析。历史测试工单不批量改名；新销售回归样例使用可读名称及有效内嵌图稿。

批量生成时，已上传图稿若加载失败，整批明确失败且不缓存错误占位文件；未上传图稿仍保留首页缺项提示。
