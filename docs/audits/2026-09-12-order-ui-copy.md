# 工单界面文案精简

## 文档先行

先在 `docs/ui-规范.md` 增加“工单文案准入与回归（2026-09-12）”，再修改界面。文案准入限制为业务事实、填写条件、阻塞及恢复、提交结果、必要操作后果；评审继续承担自动规则无法判断的语义审查。

## 执行范围

- 物料：删除库存与 BOM 机制介绍，使用“物料清单”，空数据不再猜测为未关联产品。
- 计件工资：标题明确已生成口径，删除统计机制和重复空状态介绍。
- 制版与费用：删除常驻重算、默认版费及重复保存说明；保留实际金额、表单校验、提交结果。成本补录保留防重复入账提示。
- 导出：保留 Excel 格式及 24 小时有效期，删除 SSR、进程与任务架构说明。
- 建单：精简人工核价和附加工艺说明，保留填写条件和附件/草稿限制。
- 异议：无记录只显示空状态，回复表单保留不调整报工工资的必要后果。
- 重做：移除常驻流程介绍，统一使用共享确认层展示选中款式数量、费用与原单影响；支持取消、焦点返回，确认前不调用写入操作。

## 防回归

在现有 UI 文案门禁增加按路径生效的退役文案/术语规则，并补充拦截及必要提示放行测试。没有扩充豁免或降低可访问性门禁。`pnpm lint:ui` 是提交前必需检查。

旧的工单变更集成测试使用了此前已删除变量作为源码切片边界，更新为现存边界，原权限及状态断言保留。浏览器几何/对比度检查等待弹窗动画完成后执行，避免动画中的缩放和透明度造成误报。

- 详情页浏览器检查 23 项通过；重做确认 13 项通过，覆盖取消不写入、明确确认后一次提交、焦点返回、六视口、明暗主题、触控尺寸及 axe。
- TypeScript 检查通过；ESLint 零错误，保留两处既有导航警告；UI 文案和令牌门禁零违规。
- `.github/workflows/quality.yml` 已执行 `pnpm lint`，会包含本次扩展的文案门禁。新规则对已知问题提供自动拦截，不替代语义评审。
- 未修改用户工单、价格、库存或账单数据；浏览器重做测试使用模拟写入动作。
