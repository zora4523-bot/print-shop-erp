# 管理员工单详情布局调整

## 先行规范

实现前在 `docs/ui-规范.md` 增加“管理员工单详情布局（2026-09-12）”，确定宽度、阅读顺序、移动端待办前置和不重复挂载表单的边界。

## 本次实现

- 最大内容宽度由 1280px 调为 1760px，主栏自适应，桌面操作栏 320px；960px 及以下使用单栏，待办在主内容前。后台壳自身的横向安全边距继续复用。
- 页头明确展示归属业务员、交期及总数量，移除产品客户混用；概览定位 ID 保留在页头事实区。
- 增加款式、费用、配送、生产和操作记录定位导航；沿用原有定位函数，支持展开折叠祖先、聚焦和滚动偏移。
- 设计文件紧随款式，收费维护紧随费用，配送及生产在历史记录之前。管理栏目保持默认展开；分货包装保留原先可折叠的初始状态。
- 不再用“管理与业务记录”将所有模块套在一层容器内。各模块按原 ID 在相应位置只渲染一次；未知扩展模块保留在末尾，避免遗漏调用方内容。
- 完整配送资料集中于主栏，右栏不重复收件信息；没有提供完整配送组件的调用方仍显示收件摘要。操作栏保留生产进度和当前打印入口。
- 调整标题层级、减少高字重；宽屏款式图和字段网格扩展，金额行限制阅读宽度，避免标签与金额横跨长距离。

## 范围与验证

只调整视图结构、样式和测试，不修改领域服务、金额、数据库、权限或提交参数。未对用户工单执行写入。

浏览器验收覆盖六标准视口及 2205×1203、明暗主题、长内容、多款式/多地址、预览、定位展开、待核价和变更操作。新断言检查宽屏有效宽度、小屏待办先于款式、导航目标存在及历史记录顺序。实际本地工单页面已观察到业务员标识、加宽布局和配送定位。

最终结果：详情与待办浏览器测试 35 项通过，相关页面/权限/发货契约单测 53 项通过；TypeScript、UI 文案及令牌检查通过，ESLint 无错误，保留两处既有导航警告。没有更新截图基线或放宽触控、溢出、axe 检查。
