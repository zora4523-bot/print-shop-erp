# 历史看板直接链接登录修复

开始提交 `41425f8d`，分支 `codex/historical-finance-deploy`。用户直接打开 `/historical-finance/index.html` 只看到 401 文本；该带扩展名地址不经过普通页面的代理登录引导。改动仅包含历史文件路由的未授权响应、回归验证及相关契约说明。

## 行为

- 无有效会话的 `index.html` 请求返回 307 至已有 ERP 登录页，`from` 为当前站内路径与查询参数。通过真实登录表单后返回看板。
- 有效账号缺少 `report:all` 时返回明确的 403 提示，避免已有会话在登录页与看板之间循环。
- 成功读取仍先经过 `requireSessionPermission`；失败后仅对 HTML 入口再核对账号，区分未登录与权限不足。数据库异常继续抛出，不伪装为登录失败。
- JS、CSV 等文件继续拒绝未授权访问，全部响应保持私有且不缓存。金额、历史数据、文件内容、共享登录组件及其他业务逻辑均无变化。
