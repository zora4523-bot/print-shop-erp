# 功能测试矩阵（2026-09-10）

关联：[发布结论](2026-09-10-release-readiness.md)、[开发任务](../release-remediation-2026-09-10.md)。

“单测通过”仅表示现有领域/action/组件断言通过，不表示每个 CRUD 操作都完成浏览器验收；“页面通过”仅表示登录后可加载。下面明确区分证据层级，不把覆盖率当作全功能无缺陷证明。

## 需要补齐的业务整链

下列场景已有领域测试，但本次未新增端到端浏览器事务测试，不能签署“每个功能已全面验收”：库存盘点冲突、采购部分收货/撤销、外协回货/付款、薪资计算到支付、所有主数据 CRUD、真实 OSS/企业微信、durable 导出与 PDF。

补测应使用独立库、显式业务 fixture 和真实 action，覆盖成功、越权、非法状态、重复提交、并发/金额边界及历史不可变性。执行任务见 REL-10。
