# Grok commit 审查的 Codex 复核与修复记录

**复核日期**：2026-08-27
**审查范围**：规则中心、创建工单、生产派单/抢单、客户计价、师傅计件、彩色打印/PDF
**复核方法**：不直接照单修改；逐项对照当前代码、数据库迁移、`DECISIONS.md` 与验收文档。下表只保留经 Codex 复核仍成立的问题，以及被证伪的建议。

## 结论

| ID | 级别 | Grok 问题摘要 | Codex 复核 | 处理结果 |
| --- | --- | --- | --- | --- |
| G-01 | 不成立 | 物流重量由纸张克重和数量“猜算” | Grok 与首次 Codex 复核都遗漏了权威《加工费计费规则.md》§6；文件明确规定逐款净重、克重映射、向上取整和 `2000` 个边界 | 恢复服务端版本化估算；已有履约实际重量时实际重量优先。超过边界或事实不完整才转管理员终价 |
| G-02 | P1 | 终审时完整自动费用强制覆盖管理员确认金额 | 成立。会丢失工厂终审的最终快递/纸箱金额 | 移除 `forceAutomaticAmounts` 旁路；最终金额、建议金额和原因分开保存 |

| G-04 | P1 | 拆分派单后每条师傅任务都可被写成整款数量 | 成立。多师傅分摊时计划数合计会放大 | 按“款式＋工序”做确定性整数分配；每组合计严格等于款式数量，并加并发更新守卫 |
| G-05 | P1 | 改单审批只传递旧 `foilColors/isDouble*`，丢失正反面烫金事实 | 成立 | 申请、差异、报价和写入统一使用 `frontFoilColors/backFoilColors`；旧数据仅在领域边界兼容并规范化 |
| G-06 | P1 | 打印稿把计价路线当生产工序，彩印加烫金、工厂名和任务二维码缺失 | 成立 | 打印 DTO 改读结构化正反面/覆膜/工艺事实；生产工序只来自真实任务；工单码与每任务码分开；HTML、直接 PDF 和后台 PDF 统一注入工厂名 |

| G-08 | P2 | Form B 在浏览器写死纸张/SKU/规格和 `0.1/0.2` 费率文字 | 成立 | 选项由服务端活动报价 SKU 派生；不再猜测降级产品；包装模式不显示静态费率 |
| G-09 | P2 | 已发布规则绑定产品 ID 后仍受可变 SKU/纸张/规格文本影响 | 成立 | 有 `productId` 时以稳定 ID 为权威匹配；被当前/计划价格版本引用的 SKU 禁止改写计价事实或直接停用，需新建 SKU 与新价格版本 |
| G-10 | P2 | Server Action 已 `revalidatePath` 后客户端又 `router.refresh()` | 成立。会重复发起 RSC 读取，部分组件还在 render 期调用 | 移除已有服务端再验证的成功后刷新；保留导出轮询、上传完成和传输结果不明时的手动刷新 |
| G-11 | P2 | 师傅计件快照只保存规则，没有本次计算的结构化输入/结果 | 成立 | 单条/批量报工快照保存实际数量、正反面烫金、派生倍率、板数、下数与金额；不改当前工资公式 |
| G-12 | 不成立 | 入袋费应全部转管理员手工终价 | 与 2026-08-27 业主决策冲突 | 不修。包装组事实合法且唯一命中当前 `PER_BAG` 规则时继续自动计费；只有事实/规则不完整时转人工 |
| G-13 | P1 | 整单终价预览/重算遗漏正反面烫金事实 | 成立。重复跨面的颜色会让真实烫金道数减少并命中错误规则 | 预览与 `ADMIN_FULL_REPRICE` 均读取显式正反面事实；历史无侧别数据只在领域边界回退旧聚合字段 |
| G-14 | P1 | 改单可能沿用过期人工价、漏算或重复计算包装费 | 成立。历史人工路线、带包装组的新增款和跨组归属存在失败关闭缺口 | 历史人工价只允许非结构修改；带包装组的新增款在生成待审前拒绝；同款跨组在创建、预览、内外审批均拒绝；合法多组逐组重算并保存前后证据 |
| G-15 | P1 | 大量款式、长文本或单图附件会让声明页码与物理 PDF 不一致 | 成立。浏览器会在一个声明页内再次物理分页 | 改为显式 A4 分页；款式、图稿、工序、地址和长文本均按容量续页，单/双图附件限制尺寸并保持比例 |
| G-16 | P1 | 顺丰到付提交空重量会清除已确认计费重量 | 成立。可信履约事实可能被空表单覆盖 | 只有非空实际履约重量才更新 `OrderShipment.weightKg`；浏览器更正重量不参与，服务端版本化估算仅在没有实际重量时作为后备 |

## 新旧计价模块边界

| 业务路径 | 当前权威实现 | 旧模块状态 |
| --- | --- | --- |
| 外部销售款式预览 | `quoteOrderItemsAction` → `quote-service` → `calculateExternalSalesQuote` → 当前已发布客户加工费版本 | 不调用旧 `calculateQuote` |
| 外部销售创建/改单/整单重算 | 事务内 `quoteOrderItems` 按 `EXTERNAL_SALES` 分流到同一版本引擎 | 旧价格阶梯和 `PriceAdjustment` 不参与 |
| 外部销售物流/纸箱/入袋 | `order-charge-service` → 当前物流/加工费价格版本 | 不使用浏览器金额/重量；物流版本明确配置的服务端重量估算不是旧规则泄漏 |
| 内部销售/工厂直单 | `calculateQuote` 读取 `Product.baseUnitPrice` / `PriceTier` / `PriceAdjustment` | 保留；这是明确的内部兼容路径，不是外部销售旧规则泄漏 |
