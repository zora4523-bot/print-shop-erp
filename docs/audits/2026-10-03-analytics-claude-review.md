## 修复二：已出账旧账单金额不再被跳过（已解决）
- **实现：** `reports.ts:53-55` 处理状态不是 DRAFT 的已冻结账单。分项校验失败时，金额按 `settledFeeSnapshot` 计入"已出账未分解"，同时 `uncovered++`，然后 `continue`。
  - 不会回退到当前的 `processingAmount` 或 `customerCharges`，也不会重复计算。
  - 全程用 Decimal。
- **空值与零值：** schema 第 2674 行的 `settledFeeSnapshot` 不可为空，所以不存在 null 金额；金额为 0 时会显示一行 0.00，并仍计入待核对单数，这是合理的。DRAFT 账单继续按当前收费计算。
- **测试覆盖：** `analytics.test.ts:40-43` 覆盖了分项缺失（null）和合计不符（999 对 10）两种情况，断言只有一行"已出账未分解 10.00"、提示里有"1 单"，从而证明当前收费 0.10 没有被混进来。
