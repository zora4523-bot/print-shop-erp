# 逐地址发货登记验收

日期：2026-09-11。范围：管理员物流登记、私有面单、分地址发货及最终费用确认。

## 行为与边界

- 可保存运单号、物流公司（中通、顺丰、其他名称）和可选照片；支持上传、粘贴、预览及历史照片。
- 保存资料不发货；只有管理员明确确认才更新地址状态。部分发货不提前结算，最后一票在同一事务调用现有整单发货和 v2 结算服务。
- 完工、待审变更、外协、费用确认、版本及资源所有权校验保留。最终物流重算若改变已确认金额，整个确认回滚，先完成物流费用复核再操作。
- 外部销售收费单按既有月账单规则归集；不自动生成正式账单、不改写历史账单、不登记收款。
- 图片服务端重新解码并限尺寸，数据库限制单图 512 KiB；读取要求有效登录及工单访问权限。更换照片保留历史。
- 管理员页面的旧发货入口统一指向详情登记区，旧服务契约保留兼容。

## 实际验证

- 全量 Vitest：567 个文件通过、3 个跳过；5888 项通过、55 项跳过。
- 新表单浏览器测试：17 项通过，含粘贴上传、失败重试、历史链接、六视口与明暗主题、溢出、触控及 axe 检查。
- 原列表内操作浏览器测试：27 项通过；详情页权限呈现测试包含在全量测试中。
- 独立数据库 E2E：1 项通过。真实保存面单、先发第一地址且无结算、发第二地址后写入 25.00 的结算事实；管理员图片读取 200，无关销售读取 404。
- 新空库完整迁移链：141 个迁移及后置条件通过；本地开发库已应用本次迁移。
- TypeScript 检查通过；ESLint 无错误，保留两处既有导航警告；UI 文案及令牌检查通过。
- 开发服务恢复至 `http://127.0.0.1:3000`，登录页 HTTP 200。

E2E 使用专用数据库 `erp_shipping_verify_20260911`，未对用户指定工单执行发货、结算或写入测试照片。此次 E2E 为工厂直营场景，未实际生成外部销售月账单。全量测试第一次启动停滞，终止该测试进程后重跑通过。
