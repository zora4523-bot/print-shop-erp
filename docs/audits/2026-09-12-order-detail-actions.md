# 工单详情操作集中与独立下发

## 范围与证据

按 UI 规范先记录操作集中、独立下发和遗留展示移除规则，再实施。用户标记的入口来自详情 `otherActions`，此前在页尾挂载，页头与打印区另有同类链接。现整体移到右侧待办卡片内，保留锚点、权限、禁用原因与所有操作组件，移除重复入口；窄屏随待办前置，桌面过高时侧栏可滚动。

版组/模具组 ID 和专版计价组来自详情的两个 Row，制版明细另有版组/规格占位。仅删除这些展示和对应多余网格列；字段仍被历史快照、计价及制版维护消费，因此不删除 schema、迁移、表单载荷或领域字段。

## 下发与打印边界

原单张决策面板直接调用下发并建打印任务的事务，改按钮文案无法分离行为。新增可选 `createPrint`，单张面板明确传 false，跳过打印查询/创建；保留准备检查、版本检查、待审批检查、生产激活、事务及通知。原批量组合调用不传该参数，继续生成打印任务，既有幂等重放不变。独立下发用当前版本闸口保护，不冒充打印请求重放成功；发生不确定结果需刷新核对。

独立打印入口继续沿用已有打印页面及版本授权。用户实际工单未被下发或打印；验证使用隔离测试和只读界面检查。

## 验证范围

领域测试检查独立下发确实激活生产且不查建打印任务，保留原组合事务测试；action 测试验证布尔值参数及传递；浏览器验证确认按钮传 false、失败反馈和七视口明暗布局。页面集成检查操作入口仅在右侧出现一次、遗留字段不再展示。全量 Vitest、TypeScript、ESLint 与 UI 门禁按完整变更批次执行。

验证结果：最终全量 5,911 项通过、55 项跳过；详情/待办浏览器 51 项通过，相关领域/action/页面目标测试 84 项通过。TypeScript、UI 文案与令牌门禁通过；ESLint 无错误，保留两条既有导航警告。首次全量的旧版组展示断言与新需求冲突，已改为禁止展示并重跑全量通过；一次测试进程启动停滞，仅重启本任务进程。实页观察到右侧完整操作区，未执行真实下发、发货或打印。未发布生产。
