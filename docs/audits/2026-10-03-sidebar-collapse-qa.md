# 侧栏滚动条与折叠裁切 QA

日期：2026-10-03。范围：共享 Sidebar 的滚动区、图标模式尺寸和对齐；消费者为管理员与销售导航。业务菜单、授权、路由、分组记忆、账单及写入操作保持不变。本记录不是全站业务流程验收。

## 问题与修复

- `no-scrollbar` 没有对应 CSS，实屏计算值为 `scrollbar-width: auto`。替换为组件内的标准属性和 WebKit 伪元素样式，仍保留纵向滚动。
- 原图标侧栏 48px，左右 padding 加 44px 最小点击区超过可用宽度。实屏侧栏宽约 47.44px，链接右边界约 51.99px，发生裁切。改为 64px 侧栏、44px 居中菜单按钮，为焦点环留白。
- 修复后同一账单页实屏滚动区 clientWidth / scrollWidth 均为 63px（浏览器缩放取整），scrollbar-width 为 none，按钮左右边界约 9.72 / 53.72px。
