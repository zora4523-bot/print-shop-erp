## 原因与修复

在 `/orders/new` 恢复同一草稿，保留未填的每包数量和收货地址。数量 `998 → 99` 时，旧报价错误从汇总中移除；异步报价返回后汇总重新出现。汇总原在所有输入框之前，占用 88 像素高度和 16 像素下间距：输入框纵坐标从 638 变为 534，再回到 638；`scrollY=916` 且焦点始终在数量框，确认是布局位移而非自动滚动或焦点丢失。

将错误汇总移动到所有填写区域之后。错误文字、`role=alert`、错误链接和提交失败后的主动定位保留；异步刷新不再通过顶部汇总推移输入框。该组件由管理员、销售及客服建单复用。
