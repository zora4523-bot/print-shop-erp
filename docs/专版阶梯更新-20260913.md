## 应用配置

无需修改数据库结构或重写历史迁移。新装环境完成正常迁移后，与已有环境一样执行以下价格发布步骤：

```bash
# 只读显示本次价格清单和版本，不修改数据
node --conditions=react-server --import tsx scripts/publish-confirmed-custom-tiers.ts
# 应用已确认价格；将管理员用户名替换为当前环境的有效管理员
node --conditions=react-server --import tsx scripts/publish-confirmed-custom-tiers.ts --apply --actor=<管理员用户名>
```

该命令仅适用于当前 `2026-08-30-print-null-sentinel` 加工费版本。复用现有草稿或从当前版复制草稿，校验五规格的完整性，在事务和价格写锁内改动专版基础价，通过完整规则及建单适配校验后，调用原发布流程生成新生效版本和审计记录。发布时再次校验草稿更新时间和高风险变化，保留原版规则、工单金额及快照。首次预览只列出目标清单，实际应用还会执行完整前置校验。

已有草稿含其他板块调价、基础常量变化、旧基版、缺失规格或数量重叠时拒绝更新，不夹带发布。失败事务不留下部分档位；若保存完成但发布失败，草稿保留，可排查原因后重试。成功后重复命令返回 `ALREADY_PUBLISHED`，不再生成版本；今后人工调整仍走正常规则中心流程。

价格输入框展示完整三位小数。旧十档历史版仍可展示；当前十一档包含 200 个档。数量上界输入包含该数量，500 档上界为 999；界面以“≥ 500 且 < 1,000”解释适用范围。
