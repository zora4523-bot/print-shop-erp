# 空白封纸张与规格价格管理

## 业务范围

管理员在「空白封单价」发起加工费调价后，通过「新增纸张 / 规格」选择已有纸张，或填写新纸张名称、克重，勾选适用规格并录入单价。新建同名同克重纸张时复用唯一现有记录；重复、停用、缺货或身份不完整的资料拒绝保存。

沿用 [加工费计费规则](./加工费计费规则.md) 的六种规格及尺寸：迷你封 50×80、方形 88×88、中号封 80×115、大号封 90×165、西封中号 80×120、西封大号 85×165。此入口不新增尺寸类型。纸张名称最多 60 字，克重为 1–2000 的整数；非负单价保留最多四位小数，零元与留空不同。

## 保存与生效

- 纸张主数据、可建单产品组合、草稿价格和审计在同一事务保存，使用现有价格写锁。提交携带草稿更新时间，过期页面、重复规格或任意一步失败均整体回滚。
- 新产品使用 `paperMaterialId` 关联纸张，完整规格与现有目录一致。唯一匹配的旧组合可以复用并补齐纸张关联，不重写已发布的产品计价事实或历史快照。
- 纸张和产品启用后，销售重新进入建单页即可选取；仍按工艺、规格、克重筛选有效组合。保存草稿不等于发布价格。放弃价格草稿不会删除已保存的目录，缺生效价的组合继续待核价；停用使用原有目录管理入口。
- 单价留空时只创建产品组合，不创建空金额基础规则；数据库的 `CustomerPriceRule_values_valid` 约束保持不变。销售可以选取该组合，报价进入待核价，不用零元或默认价格兜底。
- 有价格的格子在现有价格矩阵修改；为缺价格子补价或增加其他规格，再使用「新增纸张 / 规格」选择同一纸张。已有价格记录拒绝从新增入口覆盖。
- 「审阅变更 → 发布」继续执行完整规则校验、差异与高风险检查。自动报价只读当前已发布版本；旧工单保存的收费和价格快照不会因发布自动改变。
- 价格矩阵由规则与有效产品组合共同生成：有组合无报价显示「— 转人工」，不存在组合显示「不适用」。纸张不再依赖固定九行列表，列识别不再依赖产品编码后缀。

## 权限与资料保护

新页面与 Server Action 均要求 `dict:price:manage`、`material:manage`、`dict:product:manage`。客户端提交不信任纸张名称、ID、价格或草稿状态，服务端重新读取校验。

已用于建单产品的纸张不能直接改名称、克重或分类，以免纸张主数据与产品、报价身份脱节；使用新增纸张配置新组合。是否启用、缺货状态等仍由原有目录流程管理。

本次不修改 schema、已应用迁移、价格发布协议或历史订单金额；不把内部编码放到新增表单。
