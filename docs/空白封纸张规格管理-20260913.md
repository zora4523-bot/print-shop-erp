# 空白封单价与历史材料核价

> 历史记录（按文内日期理解）。2026-09-24 起角色、结算与工种口径以 SPEC §L 与 DECISIONS 为准。

本说明对应 2026-09-20 按单价管理实现。旧组合启用流程已撤除；上一阶段的实现及验证保留在[历史验收](./archive/空白封纸张规格管理-20260913-旧验收.md)。开发验证见[本次验收记录](./audits/2026-09-20-blank-price-implementation.md)，不能用旧验收证明新行为。

## 日常维护

进入「规则配置中心 → 空白封单价」，发起调价，在纸张行直接填写规格单价，保存草稿、审阅后发布。新增纸张仍可在同一页完成，无需创建产品或勾选启用规格。

- 正单价：发布并生效后可用于新空白封。红卡 180g 中号 0.135 元，1,000 个材料费就是 135.00 元。
- 0 或空白：未启用。清空已有价格会在发布后停售；新空格不生成规则。
- 保存草稿不会改变销售选项。预约发布在生效时刻改变准入；放弃草稿不改变当前价格。
- 标准规格继续为迷你封、方形、中号封、大号封、西封中号、西封大号；单价最多四位小数。机烫、制版、包装和物流各自按原规则计算。
- 资料异常会明确提示；重复纸张、缺货、停用和 120g 退役保护仍有效，不能用正价覆盖。专版与彩印仍按各自规则核价。
- 已停用且未被当前展示的价目规则引用的纸张不再占用单价表行，包括早期导入的“纸张未标”“克重未标”占位资料。仍有价格引用的停用纸张、在用资料异常和缺货继续提示；历史资料保留，停用记录仍参与同名同克重查重。

不存在单独的空白封组合启用状态。新增、复制、重做、改单新增款式（含原样复制）和改成另一纸张/克重/规格，都检查当时生效的正价。填写后停售，提交会要求重新选择；已经受理的成功请求重试返回原结果。

## 历史订单

展示与账单沿用已有金额和快照，不因价格发布改写。原款式同身份需要按现有流程重算时：

1. 当前材料价仍为正，按原重算政策使用当前价格。
2. 当前停售或缺价，仅材料费沿用该款式可验证的已确认材料单价；其余费用继续按原规则计算。
3. 缺少独立材料价，不能用整款总额除以数量猜价。管理员在工单详情「历史材料单价」填写或修改单价、填写依据并确认，再继续改单或取消核算。

补核只保存本款材料价依据和审计，不直接改写工单已确认总额，不发布新销售价格。并发修改须刷新；已结算等终态不能补核。新填单价必须大于 0；旧快照内可验证的真实 0 保留，不能成为新单可售依据。销售、客服和师傅不能通过此入口改材料价，师傅页面不读取商业信息。

取消结算先计算参考价再审批。预览后如果材料单价、产量或相关价格版本变化，原预览不能继续批准，须重新计算并核对；原有人工调整金额及填写依据的能力保留。

## 资料与用料

纸张页只维护基础资料并链接单价表。被价目、历史明细、BOM 或产品引用的纸张身份不可直接改名、改克重或改分类。

新空白封按「纸张＋标准规格」配置 BOM；用料不要求产品记录。旧订单仍读取原产品/分类 BOM。旧空白封产品及产品目标 BOM 保留为只读历史关系。专版、彩印等产品资料移入「产品结构 → 产品资料」，原启停、权限和引用检查保留。旧组合书签仅作有权限检查的兼容跳转。

## 开发与环境切换

复用 `CustomerPriceRule`，新空白封规则和明细的 `productId=null`；材料价、矩阵、目录及准入使用同一规范化文本身份。迁移为 `20260920180000_blank_price_rules`、`20260920181000_blank_bom_targets`，不改已发布价目、历史订单或已应用迁移。

现有产品 BOM 迁移工具 [migrate-blank-bom-targets.ts](../scripts/maintenance/migrate-blank-bom-targets.ts) 必须显式指定目标库，默认只读，`--apply` 才复制目标并审计；多分类不猜默认归属。复制后逐项比较用量、版本和基数，冲突整体回滚，可重复执行。默认分类只用于生产用料，不决定销售准入。

环境切换先做目标库只读预检、备份、迁移和 BOM 映射，再部署全部新读写路径。正式部署另行执行；不要把测试库结果当正式库数据结论。新格式产生后，禁止回退到仍要求空白封 Product 的旧程序；故障时保留新数据并前向修复。引用未查清的旧记录保留只读，不按类别批量删除。

回归入口：`tests/e2e/blank-price-only.spec.ts` 验真实录价、无产品建单、用料和停售；`tests/e2e/blank-paper-pricing.spec.ts` 验六视口明暗、键盘、触控和可访问性。测试使用显式指定的一次性数据库，具体命令及范围见本次验收记录。
