# 纸张、规格独立管理缩小方案

状态：范围已确认，设计待实现。日期：2026-09-20。代码核对基线：`codex/maindev` @ `b1d65751`。

## 1. 本期范围

本期只做“加”：管理员在纸张详情勾选空白封适用规格，系统创建或重新启用产品，不需要调价草稿。启用的 `Product` 承载适用关系；销售是否可选仍由现有目录条件决定，没有产品表示待设置，不表示明确不适用。

| 本期做 | 本期不做 |
|---|---|
| 空白封无草稿启用规格、确定性匹配与状态展示（S1–S3） | 下架、禁用、明确不适用；另立后续方案 |
| 纸张身份保护、新旧产品物料关联边界（S4–S5） | 新关系表、存量回填、文本准入键、入口准入校验、两次发布与回退约束 |
| 只读规格页及契约测试（S6） | 彩印自动建产品与录价（S7），专版业务改动（S9） |
| 产品组合页保留、降低日常使用频率并收紧编辑（S8） | 120g 收尾 |
| 同数据同价目版本的前后对比（S10） | 改计价公式、历史快照或历史产品 ID |

不改 schema，不改现有目录读取方；合格的新启用产品通过现有目录自动出现。纸张页复用现有目录函数，不另造可选判定。规格只读，不建表、不开放新增、改名、改尺寸或全局启停。

**业主已于 2026-09-20 确认三项：下架/不适用另立后续方案；120g 保持现状不收尾；彩印本期不做。**

## 3. 空白封启用与状态（S1–S3）

### S1 无草稿启用适用规格

- 在 `lib/price/` 新增领域操作，业务输入只有纸张 ID 与规格键数组，操作者由服务端提供。单事务，首个数据库操作取 `acquirePriceRuleSnapshotWriteLock(tx)`；不写入、不校验任何价目簿，不调用 `assertValidRuleSet`；允许为审计读取引用影响、为 S3 状态及保存复核读取现行价。
- 从 `addBlankPaperDraft` 抽取接收 `tx` 的纸张解析、产品匹配/创建函数，两个入口共用；建物料 helper 只供需要新建纸的入口使用。纸张页“新增纸张”沿用草稿约定：`paperName` 校验、名称“克重g纸名”、规格“克重g”、单位“张”，走 S4 保护；启用操作仍只收纸张 ID。原函数 262 行、门禁 300 行，不继续堆叠。
- 产品分类节点取**现有启用的空白封产品所在节点**：全部落在同一启用且未退役节点才使用；无产品、多节点或节点无效均拒绝，只提示需先确定新产品归属，不引导停用节点。草稿入口共用此解析，不再从 `STOCK_BASE` 推断产品分类节点；新规则的收费类目仍取锚点规则。阶段零不满足时，须先与业主确定归属规则再实施，不能带着拒绝上线。
- 抽取 `setProductActiveInTx`，原 `setProductActive` 保留事务薄包装，避免嵌套事务/重复独占锁；重新启用保留 `PRODUCT_ACTIVATE` 与引用影响审计。
- 写入前拒绝：纸张身份解析不出、克重超过 2000、身份在全部 PAPER（含停用）中不唯一、名称为多值；纸张停用/缺货、节点停用/退役、纸张或产品命中 `isRetiredPaper`、产品事实冲突（S2）。已有合法启用产品重复勾选为空操作。
- 新产品 `paperType`、`weight`、`specification` 分别取规范化纸张标签、解析克重、`BLANK_SPECIFICATIONS.specification`；编码沿用标签哈希加规格键。P2002 编码冲突说明存在候选规则未覆盖的同编码产品，转业务错误并引导产品组合页检查，不提示重试。
- 服务端同时要求 `material:manage`、`dict:product:manage`，不需 `dict:price:manage`、不新增权限键；现有录价入口价格权限不变。不生成默认价格，需录价仍走“空白封单价 → 新增纸张 / 规格”。

**草稿入口抽取后的行为**：采用 S2 同格筛选与候选规则（含待处理）；遇合法停用候选仍拒绝，提示先到纸张页启用，保持录价不代办重新启用的语义。外键补写按 S5；匹配规则、产品分类节点来源是有意变化，草稿/价格校验仍保留。

### S2 格子选择与待处理

两级筛选：先在空白封产品（含停用）中按“物料外键等于该纸 **或** 规范化纸张事实相同”及 `blankSpecificationKey` 等于格子键取同格全部行；多值按 `catalogPricingFactChoices` 展开识别涉及格子，不借此认作合法候选。再认规格串与 `BLANK_SPECIFICATIONS.specification` **逐字相等**的单值产品行作为候选，检查 S1 身份一致性，不取最近一条。

| 筛选结果（冲突与异常优先） | 纸张页行为 |
|---|---|
| 外键指向别纸、克重与名称冲突、外键与文本不一致 | 待处理，拒绝勾选；本期无界面修复途径，阶段零列出后走经评审的数据修复 |
| 同格存在启用的非逐字行或多值行 | 待处理，拒绝勾选，指向产品组合页检查启停 |
| 恰好一条合法启用候选，其余候选均停用 | 已启用，按 S3 展示实际可选性；以该启用行确定身份，停用行只读列出 |
| 多条启用候选，或无启用且多条停用候选 | 待处理；在产品组合页依现有保护调整启停，仅剩一条合法启用且无上述异常时自动解除 |
| 无启用且恰好一条合法停用候选 | 已停用，可勾选重新启用；复核说明可能是管理员此前刻意停用，并显示实际价格影响 |
| 无候选且无上述阻塞 | 待设置，可勾选创建 |

只有**停用的非逐字行**不参与格子状态推导、不算“已停用”，不重新启用、不补资料；不由旧停用推断不适用。产品页调整仍受生效价保护，不能承诺所有待处理都可自行解除。已启用格显示已选且不可取消；提交的规格键数组仅表示**本次新增启用**，不是全量状态。

阶段零对目标库只读预检，使用 `canonicalizeCreateOrderPaperFact`、`catalogPaperPricingFacts`、`blankSpecificationKey`、`catalogPricingFactChoices` 等真实函数：按分类/纸张事实/规格键列同格多行、规格键解析失败、克重解析失败、多值、克重冲突，以及**规格键可解析但规格串不逐字相等**六类；第六类分启用/停用，其中与标准串经 `normalizeCatalogPricingText` 后相同的单列。补列外键事实冲突、纸张身份重复、启用产品的节点分布及“无启用产品但现行价目有文本匹配规则”的格子；120g 单独分桶、不建产品。本次未查库，评审的开发库数字不作为目标库结论。

### S3 可选状态与价格同源

候选与停用行来自 S2 的直接产品查询；销售可选性将同批产品按 `listExternalCreateOrderProductOptions` 的现有条件筛选后，交给 `buildExternalOrderPapers`、`externalOrderWeightOptionsForSelection` 及同一物料输入计算。不从汇总选项反查产品，不将停用行直接喂给目录构建函数；不改现有读取方。

产品/分类启用、分类/纸张退役、克重和规格解析均影响结果；关联纸张停用/缺货可能保留为禁选项，不能仅看 `Product.isActive` 或写成从目录消失。另列只读“未归属产品”：空白封/彩印中身份匹配不到任何 PAPER 的启用产品，不自动建物料。

价格状态沿用报价的规范化纸张名、克重、规格文本口径，不按规则的产品 ID 判价。新建或重新启用后，现行价目有匹配的启用规则即按现行价自动报价，保存复核显示该价格；没有匹配价才显示待核价，不生成或改写规则，也不因此破坏草稿校验/发布投影。零价不是缺价。

## 4. 纸张身份与物料外键（S4–S5）

### S4 身份保护

身份口径统一复用适配器已导出的 `catalogPaperPricingFacts`（按多值拆分名称与规格，纸名经 `normalizeCatalogPricingText` 加克重比较），抽到共用模块供 `createMaterial`、`updateMaterial`、草稿建纸分支调用；不以单值 `blankPaperFact` 的严格相等代替。三条写入路径在同一价目快照写锁内检查；PAPER 身份集合为空时不增加身份查重/引用拦截，保留既有外键保护，启用规格另受 S1 完整性限制。

新建 PAPER 对全部 PAPER（含停用）查重，命中则拒绝；唯一停用原纸可引导重新启用，但 120g 仍禁止。`updateMaterial` 的新增身份守卫仅涉及旧或新分类为 PAPER、且身份集合不同或分类变化的更新：被移除的旧身份若仍被空白封/彩印产品文本或当前/计划生效规则引用则拒绝；若另有 PAPER 仍承载该身份（消除重复），文本引用检查不拦截，外键引用保护照旧。新集合有新增身份或分类改入 PAPER 时，对新身份集合与全部 PAPER（含停用、排除自身）查重，防止改名/改分类造重复；不限制无关资料编辑。

### S5 只给新产品写物料外键

新入口仅在创建产品时写 `paperMaterialId`；复用或重新启用无外键旧产品均不补写。补写会新增共享适配器对关联物料停用/缺货的拒绝，影响改单、工厂核价、取消结算、草稿再提交和打样等重算路径。

`addBlankPaperDraft` 现有补写逻辑本期保持原样。共用辅助函数必须显式区分两个调用入口的关联策略，不能因抽取而扩大补写范围；这是已知不一致，留给下架后续方案。无外键专版产品本来就按文本校验物料启用状态，不属于“无外键就不受影响”的情形。

## 5. 只读规格目录（S6）

空白封来源为 `BLANK_SPECIFICATIONS` 六规格，专版来源为五个必需规格。计价规范名不是可任意修改的展示名，尺寸与结构按路线分别展示。彩印没有对应常量，迁移写的是“大号88×165”“中号80×120”；禁止套用空白封尺寸。新增彩印常量前须只读核对正式库现有四个产品规格串，本期不建设彩印规格维护入口。

契约测试锁定七处现有定义：

1. [canonical-facts.ts](../lib/price/create-order/canonical-facts.ts) 的 `SPECIFICATION_ALIASES`。
2. [款式适配器](../lib/order/create-order-quote-facts-adapter.ts) 的 `pricingGroup`。
3. [规则适配器](../lib/order/create-order-published-rule-adapter.ts) 的 `pricingGroupForSpecification`。
4. 同一规则适配器的 `REQUIRED_FULL_SPECIFICATIONS`。
5. [blank-paper.ts](../lib/price/blank-paper.ts) 的 `BLANK_SPECIFICATIONS`。
6. [改单身份](../lib/order/change-request-catalog-identity.ts) 的 `pricingGroupForSpecification`。
7. [价格矩阵](../components/business/rules/pricing/CustomerPricingDedicatedSection.tsx) 的 `BLANK_COLUMNS`（键集合与空白封目录一致）。

产品生成与规则生成共用纸张标签及规格来源；测试断言产品三个字段与规则条件规范化后逐字一致。款式侧与改单侧分组一致，专版五规格集合与规则侧一致；迷你封与万元封在款式/改单侧均属 MID，不要求它们通过只服务专版五规格的规则侧分组。三条路线标准尺寸仍为 `CATALOG`，不因页面整理变成改尺寸核价。

## 6. 彩印、产品组合页与专版（S7–S9）

### S7 彩印本期不做

彩印无价产品可走 `PRINT_PRICE_NOT_FOUND` 人工核价，但现有矩阵只识别四个固定产品编码，没有为新彩印组合新增整套价格规则的业务入口；新增规则还需满足末档闭合。彩印启用与录价入口合并为后续任务。

覆膜可选性依赖纸名识别（“铜版”及 `coated` / `tbz`）；物流单重来自物流价目，当前迁移配置六个克重，未提供日常新增单重入口。空白封勾选规格同样要检查已配置克重集合，缺少时在保存复核中提示物流费用可能待定，不擅自补单重。

### S8 保留产品组合页并收紧编辑

保留创建与启停入口，专版规格仍在此维护，彩印创建保持现状。空白封/彩印已有产品的编码、规格、纸张、分类只读，领域层也保护（含无生效价产品）；编码沿用库内原值，不经 32 字符输入校验阻断其他修改，不改生成方式（方形/西封中号/西封大号分别 33/35/37 字符）。纸张页不因此开放彩印入口。

`createProduct` 新建空白封、`updateProduct` 将其他分类改入空白封时，领域层按 S2 同规则查重，命中候选或阻塞行即拒绝并引导纸张页。录错且无当前/计划生效价的产品可停用后重新勾选或新建，不提供身份改写；事实冲突仍按 S2 数据修复处理，不能以停用绕过。BOM 仍为扁平产品下拉，数据与选择行为不改。

拟简称“产品组合”；若全链路改名成本过高，可保留名称只改说明。按“可建单产品组合 / 可建单组合”检索的完整改名清单（含测试描述）：

`baseUnitPrice`、`minOrderQty`、`PriceTier` 是历史兼容字段，本期不新增、不迁移、不删除。当前产品页面不维护这些字段；通用现货、现货加烫、来料加工已整体退役，不是该页的现行业务职责。

### S9 专版不动

继续按有效 PAPER 物料与专版规格产品展开选项，保留缺货禁选、退役过滤、身份和报价校验。已发布专版阶梯每档必须覆盖五规格，不能用删掉某个规格规则来做单规格下架；产品停用另受生效价保护，不扩展任何下架能力。

**新纸张是否默认进入专版仍待业主确认，本期不实现变更。** 纸张新增后按现状自动进入专版选项；非基准纸无唯一加价转人工、冰白纸由管理员核价。在新建纸张保存复核中说明实际专版影响，不在多个位置重复说明。

## 7. 改造前后对比与实施顺序（S10）

获准实施后先做阶段零只读预检，再实现共用辅助函数、身份保护、纸张页与规格页，最后验证完整批次。当前任务仅修订文档，以下均为后续实现门禁。

固定数据与价目版本先保存改造前基线，再比较改造后同一组目录/报价入口；操作引起的数据变化另列用例：

1. 固定数据下三条路线目录选项集合、禁选状态完全相同；标准、缺价、零价、四位小数的报价分项、小计、`manualReasons`、标准尺寸判定逐项相同。
2. 新增有效纸张后专版按现状多出该纸选项；非基准纸缺加价转人工、冰白纸管理员核价均不变。
3. 停用非逐字旧行、多值行不被改写；同格启用非逐字/多值行显示待处理、不新建；同格已有两条启用产品时拒绝勾选，处理至仅一条合法启用后解除。
4. 新建或重新启用组合分别覆盖有文本匹配价/无价：可选后立即按现行价报价或待核价，复核显示实际后果；重新启用前后的目录和该组合报价按状态变化断言，其他组合报价不变，草稿保存/发布仍通过。
5. 已有合法启用无外键产品重复勾选为空操作；重新启用只改变启用状态与审计、不补外键。产品组合页新建或改入造重复格被拒；受保护长编码产品可保存非身份修改。

## 8. 移出本期：下架、不适用及 120g

下架/不适用另立后续方案。现有界面不能停用单条价目规则，清空空白封金额会被数据库约束拒绝；调整数量区间时临时停用再恢复不是下架入口。停用规则导致缺价时，改单需要人工核价，取消结算遇空金额会报错；若破坏专版阶梯闭合，还可能使价目投影失败。自动报价路径带停用产品 ID 会被适配器拒绝，影响整单重算。

产品停用不能构成完整文本准入：不带产品 ID 可被判为改尺寸，配置外说明可走人工核价。但内部建单只要携带停用产品 ID，即使带配置外说明也会拒绝。120g 的文本硬闸仍须保留。停用规则克隆草稿时保留旧金额；空白封矩阵不按 `isActive` 排除旧规则，可能将旧价显示出来，新增纸张查重也会把停用规则视为已有价格，重新启用并不对称。

`Material.outOfStock` 无应用写入口；无外键空白封/彩印产品在目录与共享适配器中不直接因物料停用而禁选，正式提交仍按文本匹配物料并检查可用性；专版无外键也会在适配器内校验物料。不能把物料停用当作整纸下架。

期间确需下架，仍使用产品组合页现有停用功能，并接受其限制：受当前/计划生效价保护，而且会阻断含该产品的在途工单重算；不能以直接改数据绕过保护。

后续方案须遵守已确认决定：**改单新增款式（含原样复制模板）按新准入拦截，模板原款式历史重算不受影响。** 先解决“历史重算是否忽略产品与物料当前启用状态”的待确认问题，再评审共享适配器历史模式及真实调用链回归；第三轮 T9 重做工单并入该方案。可比较“关系表＋入口文本校验”与“停用规则/产品＋适配器历史模式”，不在本期替业主选择。

**120g 保持现状，不收尾。** 根据 [退役记录](./audits/2026-09-17-retire-120g-paper.md)，两条物料已停用、产品与价格保留，`isRetiredPaper` 过滤新业务并拒绝物料重新启用；本次未重新查库。它还是内部配置外分支的文本闸口。矩阵已隐藏 120g，无日常收尾入口；再停用产品会把重算阻断从受物料校验影响的工单扩大到其他含该产品的工单。S1 纸张与产品两侧显式拒绝，S2 单独分桶不建产品。将来收尾前须只读确认正式库不存在可改单、可取消状态的含 120g 工单。
