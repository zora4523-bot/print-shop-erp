# 协作与表达规则

以下要求为强制要求，适用于本项目的回答、文档、注释及任务执行。

## 表达

- 使用普通中文、完整词语和明确的动宾结构，说明操作及对象；具有两个字及以上的常用形式时使用完整形式。禁止自造缩略词和商业黑话。
- 用户未要求比较时，直接陈述当前内容，禁止加入否定对照或排除项。搜索结果只呈现满足要求的内容。
- 回答直接提供任务内容，禁止总起、总结和重复复述用户指出的问题。
- 阅读代码或研究之前，禁止编造问题和预告处理顺序。方案应完整可用；多个方案应分别成立。
- 只描述当前有效设计，修改记录不得混入产品说明、代码注释或 PR 描述。
- 代码 identifier 保持英文原名；适合英文的专业名称保留英文。注释使用中文，数量以解释必要信息为限。
- 自然语言禁止使用 U+6808、U+843D、U+6B7B、U+62C6、U+504F 对应的汉字及 U+5951 U+7EA6 组成的词语。U+7C97、U+7EC6、U+786C、U+8F6F、U+5B9E、U+865A 对应的汉字仅可组成两个字及以上的完整词语，并且不能用于表达这些字的字面含义。
- 禁止评价任务工作量，禁止通过简化设计缩减任务。
- 仓库问题以证据为依据，优先控制误报；疑问句只回答问题，不附加方案、反问或执行操作。

## 执行

- 用户消息提及 AGENTS.md 时，每次重新读取该文件。
- 直接 import 必需依赖；禁止以 try-except 包围 import。成熟文件格式使用现有第三方库处理。
- 不主动进入 Plan mode；不主动使用视觉功能。
- 禁止通过 Git 恢复旧代码；需要恢复内容时使用文件编辑工具。编辑前读取当前文件，尊重用户期间的修改。
- 禁止读写 /tmp。中间结果存放在当前项目中已被 Git 忽略的专用目录。
- 使用文件编辑工具修改代码；禁止通过 heredoc、Python、sed、Perl 或其他程序批量改写代码。
- 较长脚本保存为文件后执行。Python 文件开头不添加 docstring 或 shebang。
- 需要的依赖直接使用，禁止自行替代成熟依赖以绕过安装或调用要求。
- 错误应在发生位置明确终止；禁止通过捕获或替代结果隐藏错误。
- 实现与测试使用真实行为；禁止使用 mock、伪造结果或仅为通过测试的处理。
- 提供网页链接之前阅读完整内容；发现相关库的用法错误时，重新阅读所提供链接的完整内容。
- 任务包含实施、运行、测试和必要修正，直至所需功能正确运行。途中收到可以立即回答的问题时，回答后继续原任务。
- 图示使用 Mermaid；禁止 ASCII 图示与表格。

## 用户可见文案

遵循 [文案与确认](./ui-规范.md#文案与确认)。说明应帮助用户填写字段、理解当前状态或完成操作。默认时区等通用设置由程序统一处理，字段标题使用业务名称。
